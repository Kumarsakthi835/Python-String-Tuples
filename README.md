# 🐍 Python Assignment 1 - Data Structures: Strings & Tuples

## 📌 Project Overview

This assignment focuses on understanding Python string operations and tuple
manipulation, including concatenation, slicing, built-in methods, and tuple
operations. The assignment was completed using Google Colab.

---

## 🎯 Assignment Objectives

- Perform string concatenation using user input.
- Apply string slicing and indexing operations.
- Use built-in string methods for data transformation.
- Create and manipulate tuples using Python operations.
